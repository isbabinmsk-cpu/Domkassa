# iOS Finance App - Приложение для учёта домашних финансов

Приложение для управления личными финансами в стиле iOS 2019 года с использованием SQLite базы данных.

## Функции

- **Авторизация**: Страница входа по логину и паролю (по умолчанию: `admin` / `admin123`)
- **Панель вкладок внизу**: 4 вкладки (Главная, Операции, Категории, Счета) со встроенной FAB-кнопкой
- **Категории и подкатегории**: Доходы и расходы с поддержкой подкатегорий
- **Счета**: Учёт нескольких счетов (наличные, банковские карты, счета)
- **Статистика**: Обзор баланса, доходов и расходов за месяц
- **iOS дизайн**: Стиль iOS 2019 года с анимациями и эффектами

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер по адресу: http://localhost:3000

## База данных

База данных SQLite включает следующие таблицы:

- **users** - Пользователи (логин, хэш пароля)
- **categories** - Категории доходов/расходов с поддержкой подкатегорий
- **accounts** - Финансовые счета
- **transactions** - Транзакции (доходы/расходы)
- **budgets** - Бюджеты (опционально)

### Категории по умолчанию

**Доходы:**
- Зарплата
- Бизнес
- Инвестиции
- Подарки
- Возвраты
- Другое

**Расходы (с подкатегориями):**
- Еда (Продукты, Рестораны, Доставка, Кофе)
- Транспорт (Бензин, Такси, Общественный транспорт, Парковка)
- Жильё (Аренда, Коммунальные услуги, Интернет, Ремонт)
- Развлечения (Кино, Концерты, Подписки, Хобби)
- Здоровье (Лекарства, Врачи, Спорт, Красота)
- Одежда (Обувь, Аксессуары, Уход)
- Образование (Курсы, Книги, Вебинары)
- Техника (Электроника, Приложения, Ремонт)
- Дети (Игрушки, Одежда, Обучение, Кружки)
- Другое

### Счета по умолчанию

- Наличные

## API Endpoints

### Авторизация
- `POST /api/auth/login` - Вход
- `POST /api/auth/logout` - Выход
- `GET /api/auth/me` - Получить текущего пользователя

### Категории
- `GET /api/categories?type=income|expense` - Получить категории
- `GET /api/categories/:id/subcategories` - Получить подкатегории
- `POST /api/categories` - Создать категорию
- `PUT /api/categories/:id` - Обновить категорию
- `DELETE /api/categories/:id` - Удалить категорию

### Счета
- `GET /api/accounts` - Получить счета
- `POST /api/accounts` - Создать счет
- `PUT /api/accounts/:id` - Обновить счет
- `DELETE /api/accounts/:id` - Деактивировать счет

### Транзакции
- `GET /api/transactions` - Получить транзакции
- `GET /api/transactions/:id` - Получить транзакцию по ID
- `POST /api/transactions` - Создать транзакцию
- `PUT /api/transactions/:id` - Обновить транзакцию
- `DELETE /api/transactions/:id` - Удалить транзакцию

### Аналитика
- `GET /api/summary` - Общая сводка (баланс, доходы, расходы)
- `GET /api/analytics/monthly` - Месячная статистика
- `GET /api/analytics/categories` - Статистика по категориям

## Технологии

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express
- **База данных**: SQLite (better-sqlite3)
- **Иконки**: Ionicons
- **Аутентификация**: bcryptjs + сессии

## Особенности дизайна iOS 2019

- Градиенты и тени
- Закруглённые углы (border-radius)
- Эффект размытия (backdrop-filter)
- SF Pro шрифт (системный)
- Анимации переходов
- Bottom sheet модальные окна
- FAB кнопка между вкладками
- Цветовая палитра iOS

## Безопасность

- Хеширование паролей (bcrypt)
- Сессионная аутентификация
- Валидация данных на клиенте и сервере
- Защита от SQL-инъекций (prepared statements)
